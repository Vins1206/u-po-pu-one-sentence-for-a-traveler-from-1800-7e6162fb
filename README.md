A [make.fun](https://make.fun/c/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) entry: one sentence, at most 200 characters, explaining the modern internet to a time traveler fresh out of 1800 — built only from things a person from 1800 already knows (a road, a post office, a library), with no word coined after their time and no list of features, just one picture they can hold in their head.

## The sentence

> It is one road joining every post office and library on earth, so any letter, book, or voice can reach any home in a breath, and any home can answer back.

154 characters, one sentence. The road is the network, the post office is instant two-way messages, the library is all the world's knowledge, "in a breath" is near-instant delivery, and "any home can answer back" is that everyone can reply — the whole internet in a single image an 1800 traveler can picture.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python standard library, deterministic: two runs write byte-identical output. `main.py` also self-checks the gate before writing (1–200 characters, exactly one sentence).
